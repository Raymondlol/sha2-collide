# Reference papers (not tracked)

This repository does not redistribute the reference PDFs used during development. Download them from the IACR Cryptology ePrint Archive:

- Y. Li, F. Liu, G. Wang, J. Shi. *Pushing the Limit of Memory-efficient Collision Attack Framework for SHA-2.* CRYPTO 2026. https://eprint.iacr.org/2026/1080
- Y. Li, Z. Zhang, M. Li, F. Liu, H. Qian, J. Zhu. *Pushing Collision Attacks on SHA-2 to 39 Steps.* https://eprint.iacr.org/2026/1120. Its Tables 12–14 contain the 36-step SHA-512 characteristic and the semi-free-start pair used here.
- O. Goldzweig. *A Collision for 38-Step SHA-256.* https://eprint.iacr.org/2026/2913

Put local copies in this directory. Git ignores `papers/*.pdf`.
